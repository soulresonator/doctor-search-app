# Sprint 2 Backlog

Based on the Sprint 1 Review, here is the prioritized product backlog for Sprint 2.

## Epic 1: Registration & Profile Polish
- **Task 1.1**: Add real-time validation and boundary limits to registration fields (age, phone, etc.).
- **Task 1.2**: Add "Confirm Password" field to registration.
- **Task 1.3**: Create a User Profile page (View & Edit).

## Epic 2: Patient Booking & Dashboard
- **Task 2.1**: Implement dynamic dropdowns for Specialty and Location in the search bar.
- **Task 2.2**: Add a "Reset" button to clear search filters.
- **Task 2.3**: Update Doctor Listing to include Doctor images and implement pagination/infinite scroll.
- **Task 2.4**: Create a rich Booking Modal showing doctor info and allowing Date/Time selection.
- **Task 2.5**: Create an Appointment Details Modal on the dashboard.
- **Task 2.6**: Allow patients to Cancel their appointments (remove Doctor-only 'Update Status' from patient view).

## Epic 3: Doctor Experience
- **Task 3.1**: Create a dedicated Doctor Profile page.
- **Task 3.2**: Create a Doctor Dashboard view for managing incoming appointments (Confirm/Cancel).

## Epic 4: Developer Experience (DX)
- **Task 4.1**: Build a terminal UI app (TUI) to wrap `manage.py` commands (migrations, superuser, runserver) for easier backend management.
